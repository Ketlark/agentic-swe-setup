# Banned Words, Phrases, and Openers

Statistically flagged as AI-generated text markers across multiple studies (Carnegie Mellon 2025, Wikipedia Signs of AI Writing, Buffer 52M post analysis, tropes.fyi). Never use any of these.

## Banned Vocabulary

delve / delves / delving, tapestry, landscape (figurative), testament, vibrant, pivotal, crucial, intricate / intricacies, meticulous / meticulously, bolster / bolstered, garner / garnered, underscore / underscores, interplay, multifaceted, nuanced (as filler), foster / fostering, leverage (as verb), utilize, commence, facilitate, encompass / encompassing, paramount, groundbreaking, cutting-edge, game-changing / game-changer, transformative, revolutionise / revolutionize, seamless / seamlessly, robust (outside engineering), comprehensive (describing own output), endeavour / endeavor, aforementioned, harnessing, spearheading, navigating (figurative), showcasing, highlighting, emphasizing, enhancing, unprecedented, remarkable, stunning, profound, epic (non-literal), thought leader / thought leadership, synergy / synergies, pain points, value add / value proposition, streamline, supercharge, elevate, empower / empowering, unlock, drive (as buzzword), orchestrate, transform, move the needle, bridge the gap

## Banned Sentence/Paragraph Openers

- "Certainly,"
- "Absolutely,"
- "Sure,"
- "Great question!"
- "That's a great point!"
- "I'd be happy to…"
- "As an AI…"
- "As a language model…"
- "Moreover,"
- "Furthermore,"
- "Additionally,"
- "Interestingly,"
- "Notably,"
- "Importantly,"
- "Indeed,"
- "At the end of the day,"
- "In today's world,"
- "When it comes to,"
- Paragraphs starting with "So"

## Business Jargon → Plain Language

| Avoid | Use instead |
|-------|-------------|
| Navigate (challenges) | Handle, address |
| Unpack (analysis) | Explain, examine |
| Lean into | Accept, embrace |
| Landscape (context) | Situation, field |
| Game-changer | Important, significant |
| Double down | Commit, increase |
| Deep dive | Analysis, examination |
| Take a step back | Reconsider |
| Moving forward | Next, from now |
| Circle back | Return to, revisit |
| On the same page | Aligned, agreed |

## Adverbs to Kill

really, just, literally, genuinely, honestly, simply, actually, deeply, truly, fundamentally, inherently, inevitably, interestingly, importantly, crucially, basically, essentially, arguably, reportedly, ostensibly, broadly, largely, largely, significantly, notably, reportedly, typically, generally, effectively, virtually, essentially
